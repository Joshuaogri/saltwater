## Storage observation

- Empty disposable database after 0001+0002 and rolled-back acceptance fixtures: **8,756,247 bytes** = **8.756 MB** decimal = **8.351 MiB**.
- After 1,000 synthetic people, each with one canonical profile-history row, one population-state row, one population-history row and two linked event rows: **9,706,519 bytes** = **9.707 MB** decimal = **9.257 MiB**.
- Measured incremental whole-database growth for this fixture: **950,272 bytes** = **0.950 MB** decimal = **0.906 MiB**, approximately **950.27 bytes per person** at this sample size.
- This is an observed disposable PostgreSQL 16.16 measurement for the specified compact fixture, not a production/Neon estimate. It excludes residence, relationships, jobs, police dossiers, case records, richer event attributes, narrative text, indexes introduced by later divisions, and long-run bloat.
- A clean pre-0001 database baseline and isolated 0001-vs-0002 deltas were not captured. No production capacity conclusion follows.
